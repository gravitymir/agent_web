<h1 align="center">Agentron</h1>

<p align="center"><em>Единица объёма агентской работы — и маскот, который её измеряет.</em></p>

## Что это

**Agentron** (символ **Ag**) — единица *объёма работы*, которую агент совершает за
один прогон. Она соединяет две вещи, которые реально «стоят», когда агент
работает — **сколько времени он работал** и **сколько токенов прогнал** — в одно
число, чтобы прогоны можно было сравнивать с одного взгляда.

Это не скорость: токены/час были бы *производительностью*, а Agentron — *объём
сделанного*, по аналогии с кВт·ч.

Название заодно и маскот: маленький круглоголовый бот, чьё лицо — **часы** (время),
с боковыми **ушами** и **антенной-сенсором** (связь агента с миром). Один и тот же
знак служит и логотипом приложения, и символом единицы — печатается в строке
вместо букв «Ag».

## Как считается

Для одного прогона:

```
Ag = часы × Mтокенов
```

- `часы`      — фактическая длительность прогона в часах (`duration_ms / 3 600 000`)
- `Mтокенов`  — всего токенов в миллионах (`tokens / 1 000 000`),
                считая вход + выход + кэш

Прогон в **2 часа** на **1.5M токенов** = `2 × 1.5 = 3.0 Ag`.

Считается **живьём, по каждому чату**, а не разовым снимком: `часы` копятся из
фактической длительности каждого хода, токены — из токенов чата.

Эталонная реализация — [`static/js/render.js`](../static/js/render.js)
(`computeAgentron`):

```js
export function computeAgentron(durationMs, tokens) {
  const hours   = (durationMs || 0) / 3_600_000;
  const mTokens = (tokens || 0) / 1_000_000;
  return hours * mTokens;
}
```

### Много агентов сразу

Когда работают несколько агентов, формула не меняется — агрегируются только её
входы. **Складываем длительности, складываем токены, и только потом умножаем:**

```
Ag = ( Σ часᵢ ) × ( Σ Mтокеновᵢ )
```

Это намеренно **не** `Σ (часᵢ × Mтокеновᵢ)`. Параллельные агенты делят одно и то же
окно реального времени, поэтому их совместный *объём* умножается, а не просто
складывается: два агента, каждый по 1 ч на 1M токенов, дают
`(1+1) ч × (1+1) Mток = 4 Ag`, а не `2 Ag`.

## Где видно

- **Бейдж токенов** — текущий `Ag` открытого чата рядом с живым итогом токенов.
- **Панель «Использование»** — `Ag` чата плюс эффективность `Ag ÷ ходы`
  («агентрон на один ход модели»).

Значения ниже `0.1 Ag` показываются плоским `0` — на этом масштабе значимы только
десятые.
